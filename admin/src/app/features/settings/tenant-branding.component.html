Webseite

Diese Adresse wird in der Kunden-App als eingebettete Webseite angezeigt. Darstellung und Einbettungsfreigabe werden von der jeweiligen Apotheken-Webseite gesteuert.

Damit die Webseite innerhalb der App angezeigt werden darf, muss ihr Webserver das Einbetten in einem iFrame erlauben. Header, Footer und das Design der Webseite werden nicht von AesculApp verändert. Falls Sie eine angepasste Darstellung wünschen oder die Einbettung blockiert wird, setzen Sie sich gegebenenfalls mit Ihrem Webseiten-Administrator in Verbindung.
